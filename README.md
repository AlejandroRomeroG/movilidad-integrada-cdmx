# Movilidad Integrada CDMX

Mapa web interactivo de la red de Movilidad Integrada de la Ciudad de México.

La visualización permite recorrer la transición entre el plano integrado y la geografía real, consultar el pictograma de cada estación y acercar o desplazar el mapa en computadora y dispositivos táctiles.

El sitio es estático y no recopila datos personales.
